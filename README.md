#项目名称：agent2026-book-match —— 天大二手书智能匹配助手

#作品定位
一款基于大语言模型的校园二手书智能匹配工具，帮助天津大学在校生快速找到想买的教材，或将闲置教材转售给需要的同学。

#目标用户
天津大学全体在校本科生、研究生，尤其是：
开学季购买教材时想省钱的同学
毕业季或学期末想处理闲置教材的同学
跨校区选课需要不同版本教材的同学

#核心功能
1.需求发布：用户可提交“求购”或“出售”需求（书名+联系方式）
2.智能语义匹配：调用校内词元服务（`tju-llm`），自动判断不同表述的书名是否为同一本书（如“高等数学”与“高数”）
3.自动通知：匹配成功后，分别向买卖双方发送包含对方联系方式的个性化通知
4.定时扫描：每5分钟自动执行一次匹配，无需用户手动触发

#校园应用价值
节约开支：以二手价格获取教材，降低学习成本
提高效率：自动匹配，省去翻群聊、发帖的繁琐
资源循环：促进书籍循环利用，减少浪费
